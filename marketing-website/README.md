# Marketing website assets

These are the images, logos and video for the talkingscripts.com marketing site, built in the `talkingscripts-marketing-web` repo.

This repo is public: only add files that are cleared to appear on the public website.

## Using them

Reference files through jsDelivr, pinned to a commit, so a URL never changes under the site:

```
https://cdn.jsdelivr.net/gh/TalkingScripts/talkingscripts-assets@<commit>/marketing-website/<folder>/<file>
```

When a file is replaced, commit it under a new name or bump the pinned commit in the site.

## Folders

| Folder | Contents |
|---|---|
| `brand/` | Nav logos (ink and white), the stacked splash logo, the Talking Scripts Studio logo, the App Store badge and QR code, and `share-card.jpg`: the 1200 × 630 picture shown when a link to the site is shared |
| `hero/` | The hero photo: Idris on set in a director's chair with his phone, on the right of the frame (`idris-chair-2880.webp`, plus a 1440 px version for smaller screens). `idris-purple-*`, `idris-director-chair-*`, `idris-on-set-*` and `founders-hero.webp` are earlier heroes, no longer used. |
| `try-it-out/` | The ribbon loop behind the demo (H.264, white background for multiply blending), plus its still frame |
| `demo-audio/` | The Try it out demo's Voice+ clips: one MP3 per line for each voice, in a folder per voice. Generated by `scripts/generate-demo-audio.mjs` in the site repo, which also deletes clips no longer used. Don't edit them by hand. |
| `posters/` | Key art for the "Trusted on set" wall |
| `how-it-works/` | Carousel screens: phone cut-outs (`how-*.webp`) and the full art used as blurred backdrops (`how-*-backdrop.webp`) |
| `about/` | `duo-on-set-noir-2880.webp` (plus a 1440 px version): Stefan and Idris on set in black and white, full bleed behind About. `portrait-*.webp` are the earlier founder portraits, no longer used. |
